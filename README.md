Este é o meu primeiro projeto com python puro que eu fiz e posso dizer que está levemente """organizado""" ( Comecei a programar em python desde abril de 2025 )

Esse projeto é um CRUD do sistema de uma clínica fictícia chamada "Clínica G&M"

A pessoa que vai está utilizando esse sistema será o recepcionista, na parte do cadastro tanto de pacientes quanto de médicos.

Ele irá perguntar dados do paciente como : nome,cpf,telefone e o mesmo para o médico, perguntando também o crm e especialidade

Também vai adicionar consultas e será possível ver todos esses dados através de uma tabela

Poderá remover ou atualizar consultas e entre muitas outras funções.
